## 🔍 Cómo usar esta documentación

1. **Antes de ejecutar una migración**: Lee el archivo de instrucciones correspondiente
2. **Para entender una funcionalidad**: Consulta los archivos README específicos
3. **Para configurar Supabase**: Revisa los archivos INSTRUCCIONES_SUPABASE_*

## ⚠️ Importante

- Siempre lee las instrucciones completas antes de ejecutar cualquier migración
- Mantén backups actualizados de la base de datos
- Verifica que tienes los permisos necesarios en Supabase
- Prueba las migraciones en un ambiente de desarrollo primero
